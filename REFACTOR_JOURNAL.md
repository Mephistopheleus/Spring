## Архитектура матрицы (утверждено хозяином 18.10.2026)

Два слоя с разной природой данных:

1. **Матрица (`modules/_matrix.py`) — «настоящее», только ОЗУ.**
   Кэш текущей картины прогнозов всех аналитиков с координатным индексом
   (время, цена, масштаб, тип измерения). Перезапись ячейки = семантика
   «сейчас». Память ограничена геометрией (типы × масштабы × параметры,
   несколько тысяч ячеек). Очистка по TTL. На ячейке хранятся ровно три
   вещи: значение, `ts_ms`, `seq` (указатель в журнал карточек).

2. **Журнал — «прошлое», таблица `cards` SQLite у Хранителя (уже есть).**
   История живёт ТОЛЬКО здесь — второй базы под прогнозы не строим
   (урок «neiros.base-призрака»). Назначение, квоты, чистка — у Хранителя.

3. **Нить между слоями — `lineage`** (список ссылок `card:N`/`scenario:N`/...).
   Растёт по цепочке сама: аналитик выпустил карточку → поставил lineage
   на источники. «Аналитик, анализ, аналитик, анализ…» — удлиняется
   ДАННЫМИ, а не кодом: новая схема «анализа анализов» = модуль читает
   чужие карточки и ставит `lineage: [card:родитель]`. Тюнер проходит
   по любой глубине цепочки: `deal-closed → scenario → card → …`, на
   каждом звене видит автора и вид анализа.

Правила:
- Один писатель истории — Хранитель. Матрица не хранит историю.
- Протокол «выпустил карточку — поставил lineage» обязателен для всех
  модулей (проверяем в Узле 5).
- После рестарта матрица прогревается из журнала свежайшими карточками
  по видам (ограниченный запрос, как прогрев колец), возраст помечается.

### Модуль 2. Регрессия — модернизация (консенсус хозяина/Гугла/мой, 20.10)

1. **Кинетика по-честному.** velocity/acceleration/decay — ТОЛЬКО на
   закрытых свечах (пульс между барами не врёт окнами; живая цена
   уточняет лишь угол/силу). `lifetime_min` — КАЛЕНДАРНЫЕ минуты
   состояния (метка смены знака wall-clock), не «окна подряд»: не зависит
   от темпа пересчётов. Имя поля сохранено — Интуит/Лаба/Сценарист
   читают `reg_lifetime_4h` как раньше. Свежесть показания — `ts_ms`
   ячейки Матрицы; отдельное поле age_sec не вводили (при рождении оно
   всегда 0 — враньё).
2. **G-Channel вместо SMA5−SMA34** — эталон АлексГровера (формула
   автора: `a := max(src, a_prev) − (a_prev−b_prev)/length`, `b`
   симметрично, `mid = (a+b)/2`, тренд ±1 по пробою ПРЕДЫДУЩИХ границ,
   состояние держится до пробоя). Stateless-функция `_gchannel`
   прогоняется на каждом пересчёте и побитово сверяется с независимой
   транскрипцией эталона. Старт `a = b = первая цена` (у Pine это
   nz(0)-вырождение; после length баров разницы нет). Длина — ручка
   `g_length` (100). «Плоское молчание» отменено: g-trend публикуется
   всегда: `{tf_sec, g_trend, g_upper, g_lower, g_mid}`; `value/sma5/

4. **Кросс-ТФ измерения без вердиктов** (в ответ на «общий вердикт =
   сплющенный пласт»): `atr_ratio = ATR_млад / (ATR_стар × √доли
   времени)` (больше 1 — локальный взрыв), `align = score_млад ×
